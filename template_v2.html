周转口径说明

周转天数 = 当前库存 ÷ 日均销量（分子用全部库存，不再扣死库存）

分母有两种口径，顶部「日均口径」可切换：
· 街顺日均销量（默认）= 街顺 SKU 的 day_avg_sale 字段，实测接近「近7天销量÷7」，带平滑，和街顺后台显示一致；
· 近30天销量÷30 = 严格按近30天平均，长尾/断货 SKU 数字会明显偏大。

举例（南宁西乡塘店）：库存 851 件，30天卖 11 件，街顺日均 1.4 → 按街顺日均 608 天；按 30天÷30 → 2321 天。旧版是「(库存−死库存)÷(30天销量÷30)=1426 天」，把零动销库存从分子里剔掉了，口径不透明，已废弃。

数据来源：库存、近7/14/30天销量、日均 = 街顺 API 实时快照（）；近3天销量、GMV、订单 = 星火 ERP 实际数据。

剔除口径：赠品、打包袋/包装袋（名称含「赠」「打包袋」「包装袋」等）不计入库存件数、库存金额、周转与补货，避免几十件当几百元商品拉高周转天数。
